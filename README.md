# Face-Recognition-Flask
This project is a lightweight web application built with Flask, OpenCV, and the face_recognition library for detecting and identifying faces in real time.

💡 Key Features

Upload images to detect and recognize faces

Real-time face recognition via webcam or video feed

Automatic face encoding and comparison with known faces

Simple, responsive web interface built with Flask and Bootstrap

Easy to extend for attendance systems, authentication, or surveillance

🧰 Tech Stack

Backend: Flask (Python)

Face Recognition: face_recognition (dlib)

Frontend: HTML, CSS, Bootstrap

Camera/Video: OpenCV

🚀 How It Works

Known faces are preloaded and encoded.

When an image or webcam frame is submitted, the app detects faces.

The detected faces are matched against known encodings.

The app displays recognized faces with bounding boxes and names.

⚙️ Use Cases

Attendance tracking

Access control

Visitor identification

Security systems
